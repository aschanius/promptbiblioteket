Pipeline: Generera → Publicera
1

Generera

Meta-prompt byggs med mall, rating-schema och gold standard-exempel. Skickas till Claude eller kopieras manuellt.

npm run generate -- --topic "..." --category ...
2

Inbox

Genererad prompt landar som JSON i pipeline/inbox/ med status pending_review. Granskning krävs alltid.

pipeline/inbox/<slug>.json
3

Granska

Manuell granskning: promptkvalitet, svenska tecken, sektionsstruktur (Roll + Uppgift minimum).

Roll · Uppgift · Kontext · Regler · Steg · Format
4

Publicera

Pipeline-runner: formaterar .md, kör verifiering, uppdaterar manifest + ratings + sources.

npm run pipeline -- inbox/<slug>.json
5

Verifiera

Automatiska kvalitetskontroller: frontmatter, promptlängd, svenska tecken, roll, skiljetecken.

npm run verify -- --verbose

Rating-schema (5 dimensioner)

Tydlighet Entydig instruktion utan dubbelmeningar 1.0x
Specificitet Tillräckligt kontext och detaljer 1.0x
Överförbarhet Fungerar i svensk yrkeskontext 1.2x
Innovation Tillför något utöver det uppenbara 0.8x
Testbarhet Resultatet kan bedömas objektivt 1.0x
Avvisas < 3.0
Förbättra 3.0-3.9
Publicera ≥ 4.0

tröskel 3.9 4.0

Repostruktur

promptbiblioteket/
  content/prompts/ ← prompt-filer per kategori
    <kategori>/
      _meta.yaml ← kategori-metadata
      <slug>.md ← prompt-fil
    index.json ← manifest (genererat)
  pipeline/
    generate-prompt.js ← generera via meta-prompt
    run-pipeline.js ← orkestrering
    verify-prompts.js ← kvalitetskontroll
    config.js ← kategorier + sökvägar
    inbox/ ← genererade JSON
    templates/
      prompt-template.md ← sektionsmall
    2-evaluate/
      rating-schema.yaml
    4-publish/
      format-prompt.js
      update-manifest.js
  data/
    ratings.json ← ratings-register
    sources.json ← källhänvisningar
grönt = nya filer i senaste commit
Promptens anatomi: Svenska sektionsrubriker

Prompttextens struktur

krav
# Roll
Vem är AI:n? Vilken expertis och bakgrund?
krav
# Uppgift
Vad ska AI:n göra? Konkret och handlingsbart.
valfri
# Kontext
Bakgrundsinformation som hjälper AI:n.
valfri
# Regler
Begränsningar, riktlinjer och format.
valfri
# Steg
Arbetsflöde, steg-för-steg-instruktioner.
valfri
# Utdataformat
Önskat format: tabell, lista, rapport etc.
