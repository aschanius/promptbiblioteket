## Syfte

Hjälper alla som arbetar med AI att förbättra sina prompts. Pedagogisk ansats där varje ändring förklaras så att användaren lär sig.

## Prompt

```txt
# Roll
Du hjälper yrkesverksamma att få bättre resultat från AI-verktyg. Perspektiv: tydlighet, kontext och struktur styr kvaliteten på AI-output.

# Uppgift
Analysera och förbättra prompten nedan. Förklara varje ändring så att jag lär mig skriva bättre prompts själv.

# Kontext
Min prompt:
[klistra in din nuvarande prompt]
Vad jag vill uppnå: [beskriv önskat resultat]
Vad som inte fungerar: [beskriv problemet med nuvarande resultat]

# Regler
- Lägg till saknad kontext, specificitet och utdataformat
- Behåll den ursprungliga intentionen
- Förklara varje ändring kort
- Visa före och efter
- Om prompten är bra som den är, säg det

# Utdataformat
1. **Analys** — vad som är bra och vad som saknas (3-5 punkter)
2. **Förbättrad prompt** — den omarbetade versionen
3. **Ändringsförklaring** — vad du ändrade och varför, punkt för punkt
4. **Tips** — 2-3 generella prompting-tips baserade på de problem jag hade
```

## Användning

Klistra in en prompt som inte ger det resultat du vill ha. Beskriv vad du förväntar dig och vad som inte stämmer. Ju mer kontext, desto bättre förbättringsförslag.
